# AI Engineer 학습 콘텐츠

- 콘텐츠 버전: 1.0.0
- 작성일·공식 문서 확인일: 2026-10-18
- 대상: Python·웹 개발의 기초가 있고 AI 개념을 체계적으로 연결하고 싶은 학습자
- 구성: 8개 트랙, 32개 챕터, 96개 학습 페이지
- 문제: 해설이 있는 객관식 64문항, 인출 연습 32문항과 별도 해설, 종합 상황 문제 6문항

## 읽는 방법

각 챕터는 세 페이지의 연결된 설명 글로 구성했다. 선수 학습과 학습 목표를 확인한 뒤 한 페이지씩 읽고, 읽은 내용을 한 문장으로 요약해보자. 비유는 이해를 위한 도구이며 실제 수학·모델 동작과 다른 지점도 함께 설명했다.

챕터를 다 읽으면 객관식을 풀고 정답과 해설을 확인한다. 다음으로 본문을 덮고 인출 연습을 말하거나 적는다. 같은 오답을 다시 푸는 것과 새로운 상황에 개념을 적용하는 것은 다른 연습이므로 종합 문제도 활용한다. 정답 위치보다 선택 이유를 설명하는 것이 목표다.

수치 예시는 별도 언급이 없으면 이해를 위한 가상 값이다. Python 코드는 문법·흐름 설명용이며 PyTorch 패키지 설치가 필요한 예시는 실행 환경에서 별도 확인해야 한다. 특정 모델·서비스의 최신 가격이나 순위를 암기하는 과정으로 구성하지 않았다.

## 전체 학습 순서

```text
AI의 지도와 수학
  → 데이터·머신러닝·평가
  → 딥러닝의 학습 과정
  → NLP·Transformer
  → LLM의 학습과 생성
  → RAG·검색
  → AI 애플리케이션·품질·안전
  → 배포·성능·운영
```

## 웹사이트 콘텐츠로 사용할 때

- `T01`은 트랙, `CH01`은 챕터, `CH01-P01`은 페이지, `CH01-Q01`은 객관식 문제, `CH01-R01`은 인출 연습의 고유 ID다.
- 페이지는 `### CHxx-Pxx.` 제목부터 다음 같은 수준 제목 전까지다. 확인 문제·참고 자료는 읽기 페이지와 분리한다.
- 문제는 보기 A~D와 정답·해설을 별도 필드로 나누고, 풀이 전에는 해설을 표시하지 않는다.
- `개념 ID`는 도우미 문맥·메모·오답·AI 복습 문제 연결에 사용한다. 같은 개념은 여러 챕터에서 다시 다룰 수 있다.
- 콘텐츠·문제 버전과 풀이 당시 정보를 저장해 자료 수정 후에도 과거 오답을 해석할 수 있게 한다.
- 원본은 트랙별 파일이다. 전체 통합본은 이 원본과 인출 연습 해설을 합친 읽기용 문서다.

## 작성·점검 범위

학습 순서·예시·비유·문제는 서비스 목적에 맞춰 작성했다. 각 트랙 끝에 공식 문서·교재·원 논문의 링크를 모았다. 데이터 누수, Attention 계산, RAG 평가, 생성 형식과 사실성, 동시성·재시도 등 오해하기 쉬운 구분을 본문과 문제에서 반복해 확인한다.

구조 점검은 챕터·페이지·문제 ID의 중복과 참조, 선수 학습 순서, 문항별 보기·정답·해설, 코드·JSON 문법, 본문의 주요 수치 계산을 대상으로 했다. PyTorch 코드는 구문을 검사했으며 실제 학습 실행을 완료했다는 의미는 아니다.

이 자료는 AI Engineer의 기반을 연결하는 과정이다. 고급 수학의 증명, 대규모 분산 학습 구현, CV·추천·강화학습의 전문 과정 전체를 대체하지는 않는다. 필요한 주제는 이 기반 위에서 별도 심화 트랙으로 확장할 수 있다.
